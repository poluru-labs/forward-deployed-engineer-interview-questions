# forward-deployed-engineer-interview-questions

A comprehensive open-source resource for Forward Deployed Engineer interviews, covering AI agents, RAG, system design, full-stack engineering, customer deployments, enterprise integrations, and real-world technical problem-solving.

Numbered folders are interview topics, ordered from role fundamentals through company-specific loops. The four folders at the end hold shared material used across topics: diagrams, coding problems, case studies, and references.
